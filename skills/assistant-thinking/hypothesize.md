# Hypothesize

Use observations to distinguish plausible causes instead of committing to the first explanation.

1. State the symptom, desired outcome, success indicator, and relevant constraints.
2. Gather facts from available evidence and separate them from guesses.
3. Identify distinct plausible hypotheses. Each needs a predicted observation, the cheapest useful test, and what would disprove it. Do not invent extra causes to fill a numeric quota; investigate an evidence-backed single cause directly when alternatives are not plausible.
4. Test the highest-signal, lowest-cost explanation first within the authorized scope. Record actual results rather than planned checks as evidence.
5. Mark each tested explanation confirmed, refuted, or inconclusive. Refine the test or gather new observations when results do not distinguish causes.

Return the relevant observations, hypotheses, tests/results, conclusion, and remaining uncertainty. A formal table is useful only when several explanations need comparing. Do not claim a root cause from correlation alone or implement a fix unless authorized.
