# Editing checklist

Use when revising or editing existing prose.

- Preserve meaning. Keep accurate technical terms, even when a plainer word
  seems close: a looser synonym that changes the meaning is an error.
- Match the target's existing voice, or a sample the user supplies. Do not
  impose a different register or a personal voice.
- Remove unsupported significance claims, vague attributions ("experts say"),
  promotional language, filler and generic conclusions. Judge each phrase by
  what it claims and whether the source supports it, not by whether it contains
  a particular word.
- Apply [request alignment](../../tools/progress/operating-guidance.md#request-alignment)
  for coverage and relevance: the edit serves what the user asked to change.
- Show the change as a diff or the changed section, so the user can check it.
