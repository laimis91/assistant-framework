## Problem and intended outcome

The user decided to remove `assistant-telos` completely and to retire the standalone `assistant-diagrams` skill while general diagram generation stays available. Both skills are still installed by default, because the installers add every `skills/assistant-*/SKILL.md` (install.sh:800-805, install.ps1:2471-2476). They are also wired into README, eval fixtures, contract tests and the skill-activation suite. Diagrams also carries source-backed accuracy rules and a structured feature-preparation binding that tests exercise. After this change, neither skill exists in the source tree or in any release, eval, routing or documentation surface, and no consumer refers to it. Every Diagrams obligation either has a named new owner (Docs or Workflow) or is listed as explicitly retired. User-authored Telos purpose files and unrelated content are left alone. Installed copies in agent homes are removed later by S11's mechanism, not by this slice.

The user also decided on 2026-11-06 to merge `assistant-ideate` into `assistant-thinking` now (D-S10-4). Today the two skills overlap. Thinking's `creative.md` already generates varied options and compares them against constraints, and Thinking hands broader work to Ideate twice (skills/assistant-thinking/SKILL.md:24; creative.md:3-5). Ideate's references restate its own entrypoint (skills/assistant-ideate/references/ideation-pipeline.md:3-9 against SKILL.md:15-19). After this change Thinking owns option generation and ranking, including Ideate's light mode for quick improvement scans and deep mode for explicit brainstorms, and its description and activation cases say so. `assistant-ideate` is removed the same way as Telos: every consumer is migrated, its name stays only in allowlisted historical or retirement-data files, and installed copies are removed through S11's mechanism, with the inventory entry landing in the same change.

- Default and single-skill installs add whatever `skills/assistant-*` exists. There is no separate release manifest to edit (install.sh:800-805; install.ps1:2471-2483; README.md:37 "The release inventory is the tracked `skills/assistant-*` set").

- Docs mentions diagrams only "where the project or request calls for them" (skills/assistant-docs/SKILL.md:28) and does not require every possible diagram (architecture.md:5). The migration adds accuracy rules. It does not add a diagram obligation.
