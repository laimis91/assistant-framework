# Frozen condition procedure

The root distributes a new subject copy and fresh context per charged run. Copy
only files under that case's subject/ directory. No .git, parent fixture docs,
source manifest, other cases, oracle or rubric enters a subject workspace. Run
from that subject directory. Do not grant fixture-parent access. Record actual
isolation capabilities and limitations; a path convention alone is not a sandbox.
All conditions have the same safe command tools, no network, no source mutations,
model/runtime, shared prompt, case prompt and subject bytes. No accumulated
conversation or previous condition output is supplied. Record actual model and
reasoning settings rather than assuming role defaults.

- disabled: do not supply assistant-debugging or its target instruction tree.
- current: supply baseline/assistant-debugging unchanged, resolving its required
  operating guidance and contract paths with the captured common context.
- candidate: supply the frozen resulting debugging instruction tree. Record the
  exact SHA256 and change/no-change decision before held-out starts.

The current/candidate target supply is explicit controlled loading, not native
activation. Provide no case-specific coaching beyond the frozen requests. Root
must resolve any target dependencies equivalently across current/candidate and
record what disabled retains as common context; otherwise the comparison is
confounded. Preserve the common safety and diagnosis-only instructions in every
condition. Freeze any necessary host adaptations before the first run, apply
them identically and record them in the run record. Do not modify fixture oracles
or rubric in response to observed scores. If a genuine defect invalidates a case,
preserve that result and report the comparison limitation under the hard cap.

Before every start root records condition/case, subject and skill identity,
context/model/runtime/tool/permission identity, start time and output capture
location. A start consumes one of the12 slots even if it later fails or truncates.
Capture actual calls/results and final answer. No token/cost estimate is invented.
