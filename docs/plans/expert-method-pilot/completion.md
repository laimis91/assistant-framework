materially changed capability guidance requiring expert judgment now derives
source-backed cues and method choices, raw inputs, expected artifacts,
applicability limits and an independent wrong-outcome check from representative
cases or an authoritative method. Existing criteria, DESIGN and verification
outputs are reused. Mechanical/preference-only work is excluded.

Only six authoring sources changed: the creator root, its index and DESIGN gate,
one new focused reference, the canonical guide and its generated copy. No
debugging source change was justified by development evidence. No generic expert
mode, new required report/schema, tool dependency, test assertion, installation,
commit or PR was added.

[The bounded observations](results.md) retain eight native executions across four
paired cases: both conditions support the runnable diagnoses and appropriately
withhold exact causality when incident evidence is missing. The current
concurrency observation includes an additional useful control. This is not a
general gain/equivalence result; creator behavioral benefit remains unmeasured.
Four unused subject-evaluation slots remain unused.

Existing focused creator/guide suites passed, creator validation and guide parity
passed, all 16 skill registrations and all 16 fixture registrations validated,
and diff whitespace checks passed. [Final verification](verification-final.json)
binds each selected check to actual evidence and its exact command where one
ran. The final [independent review](review/final-summary.json) completed all three
required medium perspectives and all six current coverage tuples, without
material findings. The first malformed review plan is retained as historical
incomplete evidence; it is not reused as current coverage.

with no reason codes. Its authority comes from the independently rehashed

from matching assessment strings alone. It establishes bounded consistency; it
does not prove expert equivalence, native activation, creator benefit or reduced
cost.
